구글 드라이브 자동 동기화

켜 두면 수정할 때마다 내 구글 드라이브의 앱 전용 숨김 폴더에 저장돼요. 캐시를 지워도, 다른 기기에서 열어도 로그인만 하면 그대로예요. 드라이브의 다른 파일은 볼 수 없는 권한만 써요.

클라이언트 ID 만드는 법 (처음 한 번, 5분)
  1. Google Cloud 콘솔에서 프로젝트를 하나 만들어요. Gemini 키를 만든 프로젝트를 써도 돼요.
  2. Google Drive API 페이지에서 사용을 눌러요.
  3. Google 인증 플랫폼(OAuth 동의 화면)에서 시작하기 → 앱 이름 아무거나, 대상은 외부로 설정해요.
  4. 같은 곳의 대상(Audience) → 테스트 사용자에 내 구글 이메일을 추가해요. 앱을 ‘게시’하지 않아도 나만 쓰기엔 충분해요.
  5. 클라이언트 → 클라이언트 만들기 → 유형 웹 애플리케이션. 승인된 JavaScript 원본에 이 페이지 주소를 넣어요:
  6. 만들어진 클라이언트 ID(…apps.googleusercontent.com)를 위 칸에 붙여넣고 연결하기를 눌러요. 처음엔 ‘확인되지 않은 앱’ 경고가 뜰 수 있는데, 내가 만든 앱이니 계속을 누르면 돼요.

클라이언트 ID는 비밀번호가 아니라서 노출돼도 괜찮아요. 등록한 주소에서만 로그인이 열려요.

Gemini API

평소엔 무료 키로 쓰고, 무료 한도가 차면 자동으로 유료 키로 넘어가요. 하나만 넣어도 돼요. 키는 이 브라우저에만 저장되고, 백업 파일이나 드라이브에는 들어가지 않아요.

무료 키로 보낸 대화는 구글 서비스 개선에 쓰일 수 있어요. 남에게 보이기 싫은 대화는 수집할 때 🔒 유료 키로만을 켜 주세요.

이름 인식

로그에서 캐릭터를 부르는 이름을 쉼표로 적어 주세요. 별명이나 {{user}}, 내 닉네임을 넣어두면 AI가 누가 누군지 더 잘 구분해요.
