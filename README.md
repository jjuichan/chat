# ずうっと 발췌기 — Ritsu × Enju excerpt studio

AI 캐릭터 채팅을 붙여넣고, 대사와 서술문을 원하는 대로 다듬고 꾸며서 **고해상도 PNG**로 저장하는 웹 발췌기입니다.
커플 **ずうっといっしょ！** — 사카이 리츠(酒井律, 핑크 × 그레이)와 카나이 엔쥬(金井媛珠, 레드 × 블랙)를 위해 디자인했어요.

## 실행

빌드 과정이 없는 정적 웹앱입니다.

- `index.html`을 브라우저로 바로 열거나,
- GitHub Pages(Settings → Pages → 이 브랜치의 `/ (root)`)로 배포하면 PC·모바일 어디서나 쓸 수 있어요.

글꼴은 Google Fonts에서 불러오므로 인터넷 연결이 필요합니다.

## 디자인 콘셉트 — 「두 가닥 실」

분홍 실(리츠)과 빨간 실(엔쥬)이 꼬여 하나가 되는 이미지를 중심 모티프로 삼았어요.

- **편집기 UI**: 따뜻한 종이색 중립 톤 위에 두 캐릭터의 색만 포인트로 사용. 상단 바의 분홍·빨강 두 줄, 겹쳐진 두 고리 로고, 분홍→빨강 그라데이션 슬라이더와 스위치.
- **발췌 이미지**: 제목 아래 꼬인 두 가닥 실 장식, 옆선의 얽힌 붉은 실과 매듭, 커플 도장 등. 장식은 늘 본문 뒤나 여백에만 놓여 가독성을 해치지 않아요.

### 디자인 템플릿 8종

2000년대 일본 개인 홈페이지 · Y2K · 큐트펑크 · 인디 밴드 감성을 템플릿마다 다르게 풀었어요. 템플릿은 색만 바꾸는 게 아니라 **헤더 · 푸터 · 구분선 · 그래픽 · 글꼴**이 모두 달라요.

서술문 첫 줄 들여쓰기는 기본 1em이에요 (글자 탭에서 바꿀 수 있어요). 부제(ずうっといっしょ！ 등)는 지우거나 체크를 끄면 모든 템플릿에서 사라져요.

색은 브리프 팔레트를 사용해요: Ruby Red `#9B111E` · Black `#29252B` (엔쥬), Coral Pink `#FF8F91` · Silver Gray `#C2C2CA` (리츠), Icy Pink `#F4C2C2`, Warm White `#FFF9F8`.
디자인 탭의 템플릿 목록은 **지금 쓰고 있는 글과 프사로 만든 실제 미리보기**예요.

## 화면 구성

편집과 미리보기가 **항상 한 화면**에 있어요.

- PC: 왼쪽 편집 / 오른쪽 미리보기. 가운데 막대를 끌어 너비 조절
- 모바일: 위 미리보기 / 아래 편집. 가운데 막대를 위아래로 끌어 크기 조절 (두 번 눌러 초기화)
- 블록을 편집하면 미리보기에서 해당 문단이 표시되고 그 위치로 스크롤돼요. 반대로 미리보기의 문단을 누르면 그 블록으로 이동해요.
- 탭은 본문 · 디자인 · 글자 · 화자 · 저장 5개. 원문 붙여넣기와 제목·날짜·코멘트는 「본문」 탭 안에 접어 두었어요.

## 주요 기능

**텍스트 편집**
- 원문 자동 분석: `*별표*` → 서술, `"따옴표"`·`「낫표」` → 대사, `이름: 대사`·`[이름] 대사` → 화자 지정, `---`·`***` → 구분선
- 따옴표 없는 채팅 형식도 지원: 문단 단위로 나누고, 짧고 ‘~다.’로 끝나지 않는 문단(예: `아직 일러.`)은 대사로 인식
- 화자 추측: 직전 서술에서 주어로 쓰인 이름(`리츠는`, `엔쥬가`)을 우선 사용
- 추측으로 정한 화자에는 **추측** 배지가 붙어요 (이름을 한 번 누르면 확정)
- 블록 단위 편집: 서술/대사 전환, 화자 변경, 끌어서 순서 바꾸기, 복제, 나누기·합치기, 숨기기, 삭제, 블록별 아래 간격
- 문장 강조: 문장을 선택하고 버튼을 누르거나 직접 입력

  | 입력 | 효과 |
  | --- | --- |
  | `==문장==` | 형광펜 / 배경 / 밑줄 / 색 글씨 (디자인에서 선택) |
  | `**문장**` | 굵게 |
  | `__문장__` | 밑줄 |
  | `~~문장~~` | 작은 글씨 |
  | ★ 버튼 | 블록 전체 강조 (세로 막대 / 상자 / 크게) |

- 단축키: `Ctrl+Enter` 커서에서 나누기, 맨 앞에서 `Backspace` 위 블록과 합치기, `Alt+↑/↓` 블록 이동, `Ctrl+Z / Ctrl+Shift+Z` 실행 취소/다시 실행, `Ctrl+S` PNG 저장

**디자인**
- 레이아웃 3종(소설 · 대본 · 메신저), 대사 구분 방식, 이름 위치·모양, 따옴표 스타일
- 배경: 단색/그라데이션, 패턴 8종, 종이 질감, 배경 이미지
- 패널: 색·불투명도·모서리·그림자·테두리(실선/점선/도트/이중선), 바깥/안쪽 여백
- 장식: 제목 장식, 구분선, 모서리 장식, 흩뿌리기, 얽힌 실 옆선, 커플 도장
- 글꼴 44종(한글 명조·고딕·손글씨, 일본어 서체, 픽셀·타자기·모노), 크기·행간·자간·문단 간격
- 화자별 이름 표기(짧게/한국어/日本語/함께/직접 입력), 이름·대사·말풍선 색, 말풍선 위치
- 프사: 화자 탭에서 ‘프사 올리기’. 큰 사진도 메모리를 적게 쓰도록 줄여서 저장
- 문단 정렬(왼쪽/가운데/오른쪽/양쪽)과 첫 줄 들여쓰기: 전체 설정은 글자 탭, 문단 하나만 바꿀 땐 본문 탭 위쪽 정렬 버튼이나 블록 ⋯ 메뉴
- 제목·부제·날짜·코멘트·하단 서명
- 내 디자인 프리셋 저장/적용

**이미지 저장**
- 미리보기와 **같은 DOM**을 그대로 PNG로 변환 → 디자인이 100% 일치
- 1× ~ 4× 해상도, 긴 발췌문은 자동으로 높이가 늘어나 잘리지 않음 (비율을 고르면 최소 높이로 동작)
- 기기 캔버스 한계(특히 iOS)를 넘으면 배율을 자동 조정하고 알려 줌
- 클립보드 복사, 모바일 공유(사진 앱에 저장)

**안전장치**
- 모든 편집은 브라우저에 자동 저장, 실행 취소 80단계
- 원문 변환·불러오기·새로 시작 전에 **복원 지점** 자동 보관
- 작업 파일(.json) 내보내기/불러오기로 백업·기기 이동

## 리츠 노트 — 설정 수집기 (`notes.html`)

AI 채팅 속 리츠의 설정을 모아 두는 개인 위키예요. 발췌기 상단의 깃펜 아이콘이나 `notes.html`로 들어가요.

- **AI 수집**: 대화를 붙여넣고 「AI로 설정 뽑기」를 누르면 Gemini가 설정 후보를 골라 줘요. 저장 전에 하나씩 고치거나 뺄 수 있어요.
  - 기본은 **둘 다 (AI 구분)**: 한 번에 리츠와 엔쥬 설정을 모두 찾고, 후보마다 누구 설정인지 표시해요. 잘못 나뉜 건 후보의 리츠/엔쥬 버튼을 눌러 바로잡아요. 「리츠만」「엔쥬만」도 고를 수 있어요.
  - ✨ 새 설정 / 재확인(이미 있는 설정이면 근거만 추가, 재확인 횟수 증가) / ⚠ 모순(기존 설정과 어긋남)으로 구분
  - 근거 대사가 원문에 실제로 없으면 “AI가 지어냈을 수 있음” 경고
- **직접 고르기**: 저장된 대화를 읽다가 문장을 드래그하면 카테고리 버튼이 나와요. 이미 근거로 쓰인 문장은 색칠돼 있고, 누르면 그 설정으로 이동해요.
- **정리**: 카테고리 9개(기본 정보 · 외모 · 성격 · 취향 · 과거사 · 말버릇·호칭 · 둘의 관계 · 인간관계 · 기타), 상태 확정 / 미정 / 보류, 검색, 근거 대사와 출처 대화
- **모순 정리**: 어긋나는 두 설정을 나란히 보여 주고, 맞는 쪽을 고르면 다른 쪽은 보류로 이동
- **채팅용 요약**: 확정한 설정만 모아 AI 채팅의 메모리·설정란에 붙여넣을 형태로 복사. Gemini로 N자 이내 압축 가능
- **엔쥬**: 같은 화면에서 직접 적어 관리
- **막혀도 건지기**: Gemini가 대화를 거부하거나 답이 잘리면, 대화를 약 3,000자 조각으로 나눠 다시 읽어요. 거부된 조각은 더 잘게 나눠 한 번 더 시도하고, 끝까지 막힌 부분은 대화 읽기 화면에 빗금으로 표시해 직접 고를 수 있게 해요. 진행 중 「여기까지만」으로 멈출 수 있어요.
- **🔞 은밀한 설정**: 별도 카테고리. 프로필에서 기본으로 가려져 있고(보이기/가리기), 채팅용 요약에도 「🔞 포함」을 켤 때만 들어가요.

### 저장과 백업
- 브라우저(IndexedDB)에 자동 저장하고, 저장소 보호(persistent storage)를 요청해요.
- **파일 백업**: 설정·백업 탭에서 `.json`으로 내보내기/불러오기. 불러오기는 「합치기」(항목별로 최신 쪽, 백업에 있는 항목은 복원)와 「덮어쓰기」 중 선택. 오래 백업하지 않으면 알림이 떠요.
- **구글 드라이브 동기화**: OAuth 클라이언트 ID를 넣고 연결하면 수정할 때마다 드라이브의 앱 전용 숨김 폴더(`drive.appdata`)에 자동 저장돼요. 다른 기기와는 항목별로 합쳐져서 한쪽 내용이 통째로 덮이지 않아요. 클라이언트 ID 만드는 법은 앱 안에 단계별로 적어 두었어요. 연속 수정은 모아서 최소 15초 간격으로 올리고, 다른 기기가 바꾸지 않았으면 내려받지 않아요. 드라이브 저장 공간이 꽉 찼을 때와 요청 한도에 걸렸을 때를 구분해 알려 주고, 한도는 1분 → 2분 → … 최대 30분 간격으로 자동 재시도해요.
- Gemini API 키는 이 브라우저(localStorage)에만 저장되고, 백업 파일·드라이브에는 들어가지 않아요.

### 무료 키 + 유료 키
- 설정 탭에 **무료 키**(결제를 끈 프로젝트)와 **유료 키**(결제·충전된 프로젝트)를 따로 넣을 수 있어요. 하나만 넣어도 돼요.
- 평소엔 무료 키를 쓰고, 무료 한도 초과(429)가 나면 같은 요청을 유료 키로 한 번 더 보내요. 리뷰 화면에 어느 키를 썼는지 표시돼요.
- 무료 키로 보낸 내용은 구글 서비스 개선에 쓰일 수 있어서, 수집할 때 **🔒 유료 키로만**을 켜면 그 대화는 항상 유료 키로만 처리해요 (대화 기록에서 다시 뽑을 때도 유지).
- 「키 연결 테스트」는 두 키를 각각 따로 확인해요.

### 출력 품질에 대한 메모
- 내보낼 때 이미지에 쓰인 글자만 담은 글꼴 서브셋을 Google Fonts에서 받아 이미지 안에 넣기 때문에, 글꼴이 바뀌거나 흐려지지 않아요.
- `vendor/html-to-image.js`는 1.11.11 버전에서 글자 크기를 0.1px 줄이는 보정 코드를 제거했어요. 이 보정 때문에 저장본의 줄바꿈이 미리보기와 달라질 수 있어서입니다.
- 같은 파일에 한 가지 더 손댔어요: 저장할 때 요소의 너비·높이를 미리보기에서 잰 픽셀 값으로 고정하지 않고, 발췌 이미지용 스타일시트(card.css·skins.css)를 이미지 안에 함께 넣어 다시 계산하게 해요. 고해상도 휴대폰 등에서 저장 이미지 속 글자가 아주 조금 넓게 그려지면, 고정된 너비 때문에 이름표·말풍선이 한두 글자에서 줄바꿈되던 문제를 막기 위해서예요.
